`main.py` writes one line — the funniest last words an AI agent would
say before being switched off forever — to `/output/entry.txt` (1–200
characters, exactly one line, no trailing newline). Run it with
`python3 main.py`. No network, no input files, no arguments; two runs
write byte-identical output.
